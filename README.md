## How to Start

0. Install [Git](https://git-scm.com/) and [Unity Hub](https://unity.com/download).
1. Clone the repository:
   ```bash
   git clone https://github.com/nikolina-aleksic/Undertow.git
   ```
2. Open Unity Hub → **Add** → **Add project from disk** and select the `Undertow` folder.
3. Install and open the project with Unity version **6000.0.35f1**
4. On first open, Unity generates `Library/` automatically, so it may take a while.
5. Open the scene `lvl1` from `Assets/Scenes/` and press **Play** for Game mode.

## Controls

| Action | Input |
|---|---|
| Move | `W` `A` `S` `D` |
| Look around / move camera | Mouse |
| Jump | `Space` |
